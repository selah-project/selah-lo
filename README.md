# ພຣະຄຳພີເຮັບເຣີ (ທານາກ) — ສະບັບແປພາສາລາວ

ພຣະຄຳພີເຮັບເຣີ (ທານາກ) ແປເປັນພາສາລາວ — ຂໍ້ຕໍ່ຂໍ້, ຄຳຕໍ່ຄຳ,
ພ້ອມຄຳອະທິບາຍໃຕ້ທຸກຄຳເຮັບເຣີ.

ນີ້ແມ່ນ **ຕັ່ງທີ 67** ຂອງໂຄງການ Selah — ຕັ່ງພາສາລາວທຳອິດ,
ຕັ່ງທຳອິດຂອງຕະກູນພາສາກຣະໄດ. ບ່ອນເກັບ: `selah-lo`.

## ເຮັບເຣີມາກ່ອນ

ການແປນີ້ມີໄວ້ເພື່ອນຳທ່ານໄປຫາຕົວໜັງສືເຮັບເຣີ — ບໍ່ແມ່ນມາແທນທີ່.
ສິ່ງທີ່ທ່ານອ່ານແມ່ນເຮັບເຣີ: ຕົວອັກສອນ, ສຽງ, ເຄື່ອງໝາຍ.
ແຖວພາສາລາວຂ້າງລຸ່ມແມ່ນປ່ອງຢ້ຽມເບິ່ງ, ບໍ່ແມ່ນຕົວແທນ.
ຖ້າສອງຢ່າງບໍ່ກົງກັນ, ຄວາມຈິງຢູ່ໃນເຮັບເຣີ.

## ສິ່ງທີ່ການແປນີ້ບໍ່ແມ່ນ

- **ບໍ່ແມ່ນຕົວແທນພຣະຄຳພີຂອງທ່ານ.** ຈົ່ງຮັກສາພຣະຄຳພີຂອງທ່ານ,
  ອ່ານມັນ, ອະທິຖານກັບມັນ. ວຽກງານນີ້ຢືນຢູ່ຂ້າງໆ — ຊີ້ໄປຫາ
  ຕົວໜັງສືເຮັບເຣີ.
- **ບໍ່ແມ່ນຄຳສອນສາສະໜາ.** ພຽງແຕ່ຕົວໜັງສື, ຄຳຕໍ່ຄຳ,
  ກວດສອບໄດ້ທຸກຂໍ້.
